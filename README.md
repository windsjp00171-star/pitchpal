# 🎵 PitchPal — 敬拜調 Key 工具

專為敬拜帶領者打造的一站式音樂工具。上傳音頻、自動偵測調性、移調、試聽旋律與和弦，全部在瀏覽器完成，不需安裝任何軟體。

---

## 功能總覽

### 🎚️ 調 KEY 工具
- **自動調性偵測**：使用 Krumhansl–Schmuckler 音調輪廓法，分析音頻核心段落並多窗口投票，輸出調性與信心度
- **手動修正原 Key**：偵測有誤時可手動覆蓋，移調計算與 Capo 建議即時更新
- **半音滑桿移調**：拖動滑桿（-12 到 +12 半音），即時顯示移調後調性
- **Capo 建議**：自動列出吉他常用 Capo 位置與對應指型
- **YouTube 下載（實驗性）**：貼上連結直接分析，成功率約 40–60%（雲端 IP 限制）
- **支援格式**：MP3、WAV、M4A、FLAC、OGG、OPUS、MP4、MKV 等
- **輸出格式**：WAV（無損）、MP3

### 🎼 旋律試聽
- **數字簡譜輸入**：支援 1–7 音符、升降號（`#` `b`）、八度移位（`'` `,`）、八分音符（`_`）、十六分音符（`__`）、附點（`.`）、延音（`-`）
- **音符調色盤**：點按 1–7 及 0 休止符直接輸入，可搭配升降、八度、時值修飾按鈕
- **和弦進行輸入**：用 `|` 分小節，同小節和弦自動平均分配拍數
- **和弦調色盤**：7 個順階和弦按鈕，隨調性自動更新標籤；9 種和弦色彩（基本、小調、小七、藍調七、大七、掛四、掛二、加九、減）
- **6 種音色**：鋼琴、吉他（Karplus-Strong）、長笛、管風琴、豎琴、小提琴
- **節拍器**：可開關，強拍 / 弱拍頻率不同，音量獨立調整
- **拍號**：4/4、3/4

### 🔍 音頻轉譜（實驗）
- 上傳音頻，自動輸出旋律簡譜粗稿（pyin 基頻偵測）與和弦進行粗稿（chroma 模板比對）
- 適合單聲部人聲或簡單樂器，輸出為可編輯粗稿

## 快速開始（本機）

```bash
pip install -r requirements.txt
python app.py
```

需要 Python 3.10+，建議安裝 ffmpeg 以支援 MP3 輸出與影片格式。

## 數字簡譜格式說明

| 輸入 | 意思 |
|---|---|
| `1` – `7` | Do Re Mi Fa Sol La Ti |
| `4#` | 升半音 |
| `1'` | 高八度 |
| `1,` | 低八度 |
| `1_` | 八分音符（半拍） |
| `1__` | 十六分音符（¼拍） |
| `1--` | 延音，幾個 `-` = 幾拍 |
| `1.` | 附點（× 1.5 拍） |
| `0` | 休止符 |
| `\|` | 小節線 |

**範例（G 調，遠超過諸天 Intro）**

旋律：
```
5 6 7 5 3 - - - | 7 5 6 - | 4# 5 6 4# 2 - | 6 4# 5 -
```
和弦：
```
C Em7 | D | G/B | Em7 D
```

## 技術棧

- **Python + Gradio 5** — 介面
- **librosa** — 調性偵測（Krumhansl–Schmuckler）、移調（phase vocoder）、旋律偵測（pyin）
- **soundfile / scipy** — 音頻 I/O 與濾波
- **yt-dlp** — YouTube 音頻下載
- **ffmpeg** — 格式轉換
